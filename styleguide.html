Rules

npm run styles:check fails on any of these:

  • a sheet that index.css does not import, an import of a missing sheet, or tokens.css not imported first;
  • a selector group owned twice in one scope, in any file, a property repeated within a rule, or !important;
  • a custom property declared outside tokens.css :root, a var() naming an undeclared token, or a var() fallback;
  • outside tokens.css: a literal or named colour, a --c-* primitive, or a literal font size, font weight, radius, duration or layer;
  • a media query on a width or height outside the breakpoint set;
  • in TypeScript: a literal colour (outside the skill-domain palette module), a primitive, or an undeclared token.

Geometry that belongs to one component — a width, an offset, a minimap size — stays literal in that component's rule.

npm run styles:dead reports class names no source file references, matching whole identifiers. Review its list before running styles:prune: a class composed at runtime can look unused to a text search.
