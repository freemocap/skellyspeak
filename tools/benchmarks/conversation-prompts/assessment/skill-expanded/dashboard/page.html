What this study can support

Interpretation of the full study · all 108 cases

The longer guide (E) scores 1.67 percentage points above language guidance (B), but its paired 95% interval spans −2.04 to +6.93 points. That does not establish an improvement—or equivalence. Its observed cost is about 21% higher.

Removing the 30 cases flagged as disputed before inference raises agreement to 93.2–94.4% and changes the highest point estimate from E to D. The ranking is sensitive to the references. Review those cases before choosing a prompt based on this result; unflagged labels are also provisional.

Repeated choices disagree in roughly 1.4–2.3% of valid pairs. Jev is usually consistent on these repeated inputs, but consistency alone cannot settle whether its interpretations or our references are correct.

Design

  • 108 cases: 36 scenario rows expressed in Spanish (Mexico), Levantine Arabic and MSA.
  • 31 semantic clusters group translations and related cases.
  • Five prompt conditions × five repetitions = 2,700 sequential requests.
  • Each request asks evidence and expression questions for both skills. Primary plots use only the case's focal skill to avoid inflation from unrelated absent skills.
  • Shuffled case order each repetition; rotating condition order. Seed 938174. No automatic retries. The initial transport timeout was deliberately retried once; structured-validation failures were retained without retry.
  • No documented temperature parameter in the Decisions API. Temperature was omitted; repeated calls measure variability under service defaults.

Content conditions

  1. Shared core definitions and assessment instructions.
  2. Core + language-specific guidance.
  3. Language guidance + relationship meaning in prose.
  4. Language guidance + relationship notation.
  5. Language guidance + longer guide specimen.

Arabic has its own guidance referencing the selected variety; it is not evaluated using Spanish instructions. These are experimental specimens, not finished guides.

Uncertainty and limits

The point estimate weights cases equally and averages the five repetitions and selected judgment dimensions. The 95% intervals use 5,000 resamples of the 31 semantic clusters, with replacement. Every selected translation and repeat stays in its cluster. Arm differences use the same resample for both arms.

These intervals describe sensitivity to the scenario collection. They are not a guarantee about arbitrary learners. Five repeats only weakly characterize rare instability. This is a convenience set with provisional labels, no independent review and no held-out validation.

Language comparisons mix translation and expression differences with model behavior. Inspect disputed cases before attributing a difference to a language. Label disagreements can reveal problems in the definition or reference, not just in Jev.

Evidence and expression are separate judgments. “Successful” means communicating the target meaning; it does not require error-free grammar. This distinction needs human review before XP uses it.
