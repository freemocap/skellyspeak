# prompts

`assessment/` contains skill questions, criteria and evidence-location instructions. `conversation/` contains named instruction fragments and structured options. `practice/practice.md` contains practice instructions. Markdown is model input; READMEs are not. Native assembly must record exact source paths and revisions. Credit thresholds belong in `policies/`.

`skills/guide-translation.md` translates authored explanation fields on demand. Native assembly supplies the source edition and a structured output contract; example text is retained unchanged.

`skills/coach-guide.md` introduces a guide attached to a coach question. Native assembly supplies the exact guide, source paths and revision as reference data.
