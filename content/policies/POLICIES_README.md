# policies

`teaching-policy.yaml` declares teaching, feedback and reward configuration. `skill-credit.yaml` declares the main-skill correct-use threshold. Model instructions belong in `prompts/`; language facts belong in `languages/`.

`guide-authoring.yaml` declares each target language's source explanation edition
and the English, Spanish and Arabic bundled translation target. Source guides and
assessment guidance are mandatory. Other explanation editions can be translated
on opening and cached locally; bundled translation gaps do not block readiness.
