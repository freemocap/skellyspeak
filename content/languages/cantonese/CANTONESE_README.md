# Cantonese

Hong Kong conversational Cantonese is a peer learning language with stable ID
cantonese and variety cantonese-hong-kong. Its external tag is yue-Hant-HK.
Writing uses Traditional characters; reading assistance uses LSHK Jyutping.
Colloquial grammar, writing convention and romanization are separate guidance.

The language file owns the profile, practice material and starter partner. Eight
skill folders contain assessment guidance and English and Cantonese learner explanations.
Cantonese is also an interface and explanation language: selecting 廣東話 as the
app language seeds Hong Kong Cantonese explanations. All 21 learning languages
have bundled Cantonese skill guides, including Mandarin and English. The
interface and guide prose use Traditional characters and Cantonese wording;
quoted target-language examples retain their original spelling and script.
Content is source-informed AI authoring marked needs_review, not a linguistic
quality certification. See [implementation and verification](../../../docs/notes/cantonese-speech-support-audit.md).
The [interface and explanation report](../../../docs/notes/cantonese-interface-and-explanations.md)
records direct authoring, coverage and checks for Cantonese-speaking learners.
