# Mandarin

- `mandarin-language.yaml`: identity, varieties, writing systems, speech preferences, conversation starters and practice material.
- `skills/<skill>/`: assessment guidance and learner explanations for each skill.

Assessment files are independent of explanation language. Learner explanations reference the matching shared explanation in `content/skills/`.

The display name is Mandarin Chinese / 普通话. Stored IDs remain mandarin and
mandarin-mainland-china, preserving existing conversations and learning records.
The initial profile retains Simplified Chinese and Hanyu Pinyin. Cantonese is a
separate peer language; Taiwan Mandarin and additional script choices are deferred.
