SkellySpeak · design system companion · gloss + reading

Understanding a word, in three depths

This restyles real, already-working mechanics — SavedGlossText.tsx, GlossPopup.tsx, TargetText.tsx — under the laws from the main system doc, and adds the two pieces that were genuinely missing: a tiered reveal instead of everything at once, and a per-message override beside the existing global reading preferences.

01 · what already exists

Three interactions on one word, already

Reading the source made this a restyle, not a rebuild. A saved word already has a mouse-hover preview (an ephemeral floating card, positioned by SavedGlossText's own layout effect), a tap that toggles a persistent inline reveal, and a right-click that jumps to the Analysis pane. Global reading preferences (autoTranslate, alwaysRomanize, alwaysPronunciation) already suppress the reveal for whichever field is set to always-show. What's missing: the reveal shows every field at once instead of in tiers, and there's no way to override the global default for one message.

Hover · mouse only An ephemeral floating card, anchored above the word, showing whichever fields aren't already always-on. Gone on pointer-leave.
Tap · persistent Toggles a saved reveal — today, every field appears at once, inline, right after the word. This is the one this section retiers.
Right-click · cross-reference Pins the turn and jumps the study pane to Analysis with this exact token highlighted. Untouched by this pass.
02 · try it

Tap a word below — this is live

Tier one is the translation, alone. A small "more ▾" control — not a second tap on the word itself, so it can't be mistaken for closing the reveal — expands romanization and a short usage note. Tap the word again to close everything. On desktop this renders as a popover, reusing GlossPopup's existing anchor/clamp logic; wide-window here, so you're seeing that path.

¿Sabes dónde puedo encontrar una farmacia por aquí?
pharmacy
far·ma·cia Feminine despite the -a not being the only tell here — farmacia is one of the common "-ia" borrowings from Greek via Latin.

Underline = has a saved gloss. Tap toggles the popover; "more ▾" toggles the second tier independently.

03 · same tiers, narrow width

Inline instead of floating — nothing else changes

No room to float a card without covering the next line, and no hover to preview first — so narrow width skips the popover shell and appends the same two tiers directly after the word, pushing the line. Same content, same two-tier structure, different container.

04 · multi-clitic words

One tap, every fragment together

Arabic clitics are already grouped server-side — glossDisplayGroups keeps one orthographic word as one tap target even when it carries three separate glosses. Tapping it opens every fragment stacked, each labelled with the exact source substring it belongs to — never guessed positions, never re-split characters.

05 · per-message override

The conversation sets a default. Any message can differ.

Reading preferences stay global — that's still the useful default. What's new: a small icon in the message-action row overrides translation for just that reply, without touching the setting for every other message.

Conversation default: translation off
Claro. ¿Para tomar aquí o para llevar?
This message, overridden on
Claro. ¿Para tomar aquí o para llevar? Of course. For here or to take away?

The checkbox-style icon is the override state, not a new button — filled means "on for this message," and it sits in the same action row as Translate/Explain/Read aloud, same order as the main system doc.
