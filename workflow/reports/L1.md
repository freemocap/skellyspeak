## Implemented

Added `src-tauri/src/linguistics/adapter.rs` and `adapter_tests.rs`. The only accepted
core source edit is `pub mod adapter;` plus its separating blank line in mod.rs.
Updated ADAPTER-PROPOSAL.md, CONTRACT.md and this report to state current behavior.

`decode_word_gloss` consumes raw candidate JSON directly using serde, without a Value
map that could collapse duplicate keys. It rejects unknown/duplicate/missing fields,
nulls, numeric IDs, wrong variants, fenced/trailing/malformed content and invalid anchors.
The bounded sequence visitor refuses a 513th span before decoding its contents.
Response content is capped at 128 KiB before parsing. It maps boundary IDs through
the accepted grapheme-safe source map, preserves ordering, and invokes the accepted
validator. Every gloss reuses provider::validate_prose and the tighter core length
limit; no prose check modifies or excludes original source text.

The minimal candidate variants are gloss(start/end/kind/gloss) and literal(start/end/
kind). Missing non-whitespace coverage stays unresolved/partial; explicit literals
carry no help. Complete coverage with zero glosses is distinct from available help.
Errors contain fixed codes and item indices, not raw JSON/parser errors/source text.
Excess item count is reported as InvalidJsonOrShape, not a content-bearing parser error.

`build_word_gloss_prompt` creates two existing PromptMessage values using escaped JSON:
fixed instructions/schema plus exact passage, native validated language IDs and a
catalog of complete grapheme fragments. The fragments reconstruct source exactly;
AI may group multiple fragments into a linguistic word. There is no whitespace or
punctuation word tokenizer. Boundary IDs, template and policy are deterministic.
Serialized prompt messages are capped at 256 KiB; future provider token/capability
checks remain necessary. The returned schema is a candidate schema, not a claim of
endpoint compatibility or measured model quality.

Both APIs reject unsupported target/explanation language IDs using languages::language
and reuse core source/version eligibility. No new registered languages or external
route are inferred from mixed scripts. Caller-owned immutable source/attempt binding,
stop termination and transactional publication checks remain execution obligations.
