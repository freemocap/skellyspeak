# Working notes

This folder holds notes and planning material worth keeping in the repository
that do not belong in the published documentation or maintained user and developer
guides. Use it for investigations, proposals, open questions, implementation notes,
verification reports, and handoffs.

## How to use it

- Write new working notes here, rather than scattering them across the repository
  root, source folders, or documentation website.
- Use descriptive filenames. Group related notes in a topic folder when useful;
  date snapshots and reports when their timing matters.
- State whether a note is a proposal, an agreed decision, an observation, or a
  verification result. Distinguish implemented behavior from intended behavior.
- Update an existing note when continuing the same topic. Mark superseded material
  and link to its replacement instead of leaving competing accounts of the truth.
- Promote settled information into the appropriate maintained guide when it
  belongs there. A note is not authoritative just because it is in this folder.

These notes are stored in the repository and may be publicly readable; they are
not private storage. Historical material in [old/notes/](../../old/notes/) remains
archived and potentially inaccurate. Do not move it here wholesale.
