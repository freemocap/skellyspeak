# Find your way around

The top bar stays with you while you move between the app's main screens. **Chat is home**: select the SkellySpeak name or logo to return to your conversation.

<UserDemo view="navigation" />

## Choose a destination

| Control | What it opens |
| --- | --- |
| SkellySpeak name or logo | Chat and your current conversation. |
| Language picker | The language you are practising. Each language keeps separate progress. |
| Practice (flexed arm) | Cards for listening, recording and comparing repeated phrases. |
| Progress (open book) | The Skills, XP and Effort tabs. |
| Skill level and its small chart | The Skills tab for the current language. |
| Language XP | A summary of language totals; expand it to open the XP tab. With touch, the first tap shows the summary. |
| Settings gear | App-wide settings. On narrow screens use More → Settings. |
| More (three dots) | Settings, Browse languages, Progress, AI activity, logs and Reload app. |

On smaller screens, some labels and controls move into menus. **Practice** and **Progress** retain their destination icons. Use **More** when a setting is no longer visible in the top bar.

## Controls inside Chat

**Conversations** opens saved conversations and the **New conversation** action. Opening another conversation changes which message history and coach context you are viewing.

**Conversation settings** belongs to the current conversation. App-wide **Settings** controls AI access, voice, appearance and other preferences. They are separate panels.

The learning panel has **Coach** and **Progress** tabs. Its Progress tab concerns the conversation; the top-bar Progress destination opens the broader language report.

## Read common icons

| Icon or control | Action |
| --- | --- |
| Microphone | Start recording; the control changes while recording. Read its label before stopping. |
| Play triangle | Play the associated message or recording. |
| Up arrow in the message draft | Send the draft. |
| ↗ beside a suggested reply | Insert that reply into the draft without sending it. |
| Sun or moon | Switch between light and dark appearance. The adjacent chevron opens the palette choices. |
| Sliders in Chat | Conversation settings. The app-wide Settings control uses a gear. |
| Practice cards with a plus or check | Add a phrase to Practice or manage its saved status. |
| Chevron beside a section | Open or fold the section. |
| Three dots | Reveal additional actions that do not fit in the current toolbar. |
| Trash | Delete or discard the item named by the control. Check the label and confirmation. |

Keyboard users can tab to controls to read their accessible names. In a message draft, **Enter** sends and **Shift+Enter** inserts a new line. Custom app shortcuts are under **Settings → Shortcuts**.

## Leave a panel

Use its close control, press **Escape**, or select outside a dismissible dialog. Returning to Chat does not mean starting a new conversation. To start another, use **Conversations → New conversation**.
