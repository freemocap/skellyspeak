# Read your progress

Open **Progress** in the top bar. Choose **Skills**, **XP** or **Effort** according to what you want to inspect. The selected language determines the language report.

<UserDemo view="progress" />

## Choose the right tab

| Tab | What it reports |
| --- | --- |
| Skills | Evidence for eight conversation skills, their points and practice levels. |
| XP | Skill XP, effort XP, contributing messages and the history behind those points. |
| Effort | Counts of recorded activities, recent activity and timestamped history. |

Language XP and effort are kept separately for each language. The **All languages** table lets you inspect another language. Its global XP total is the sum of the XP for each language.

## Inspect XP

1. Open the **XP** tab.
2. Check the selected language, total XP and breakdown into **Skill XP** and **Effort XP**.
3. Select a skill in the breakdown to inspect its guide and supporting evidence.
4. Open **Your learning evidence** for assessment records grouped by partner and the YAML export action.

The current report defines Skill XP as one XP for each skill a message uses for the first time, and Effort XP as one XP for each skill a changed retry keeps. A message can involve more than one skill.

Opening a reward or inspecting an old message does not award it again. Animations and sounds present recorded credit; they are not additional credit events.

## Inspect effort

Open **Effort** to see activity totals, additions in the last seven days, active days and counts per active day. Active days are grouped by **UTC**, as labelled in the report.

Use **Show** in the history to filter a kind of activity, then inspect its timestamp and source when available. **Load more** retrieves additional entries. Earned effort counts can remain after source history is deleted; the report labels that missing source rather than inventing text.

Effort counts and Effort XP are different measures. The former count activity; the latter belong to the XP rules shown in the XP tab.

## Interpret the limits

These reports describe activity and model-assessed evidence in SkellySpeak. They are not standardized language tests, proficiency certificates or proof of mastery. A pending or failed assessment can leave evidence incomplete.

When a number seems surprising, inspect its source, assessment details and assistance information. The [Skills guide](./skills) explains practice levels and how to exclude a questionable assessment from progress.
