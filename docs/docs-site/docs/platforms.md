## iOS

If you have a TestFlight invitation, open it on your iPhone or iPad, follow its
TestFlight installation steps, then install SkellySpeak from the invitation.
An IPA attached to a GitHub release is not a direct-install package for an
ordinary iPhone. Without an invitation, check with the person coordinating your
test access; downloading the IPA does not grant access.

For desktop and Android installers, use the [downloads page](/download).
