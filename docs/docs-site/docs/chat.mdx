# Have a conversation

Use Chat to practise responding to a partner in context. You can type, speak, inspect unfamiliar words, or ask for help with a reply.

<UserDemo view="chat" />

## Start an exchange

1. Select the language in the top bar and return home with the SkellySpeak name or logo.
2. Open **Conversations → New conversation** when you want a fresh exchange.
3. Before beginning, open **Options** to review the starting difficulty and conversation preferences. Inspect or change the partner if needed.
4. Choose a suggested topic, enter your own topic, let the partner start, or send your own first message.

Difficulty changes the requested language level. It is a preference for generated language, not a measurement of your proficiency.

## Type a reply

Use the typing control in the message area to reveal the draft. Write your reply, then select the **Send** arrow or press **Enter**. Use **Shift+Enter** for a line break.

A reply may arrive before its reading help and assessment finish. Each operation has its own status; a visible reply does not mean every background result is ready.

## Speak a reply

1. Check the selected microphone in the recording controls.
2. In tap mode, select the microphone to start and again to stop. In hold mode, hold the recording control while speaking and release it when finished.
3. Wait for transcription. With **Auto-send** off, the transcript becomes an editable draft.
4. Check the words and send. With **Auto-send** on, the app sends the transcript automatically.

For a first attempt, leave Auto-send off so you can check what the recognizer heard. Chat's automatic pause-based recording mode is labelled **Coming soon**; continuous attempt detection is available in [Practice](./practice).

## Understand the partner

Click or tap an interactive word to open word help; with a mouse, pausing over the word also opens it. Select **Analysis** in that help card for deeper inspection. Preparing a missing meaning or requesting deeper help can require AI access.

Use the message's translation and playback controls when you need the whole sentence. **Translation**, **Romanization** and **Pronunciation** preferences control different reading aids; an approximate pronunciation guide is not a recording or an assessment of your speech.

For more context, open **Help understanding this message**, **Explain grammar**, or **Suggest a reply**. These results can finish independently. Reopening saved help does not itself request a new answer.

## Use a suggestion

Open **Suggest a reply**, read the options and select the **↗** beside one. It fills your draft without sending. Edit it to express what you mean, then send it yourself. Sentence starters work the same way.

The app records in-app assistance when assessing learning evidence. A suggested reply is useful practice, but assistance should not be mistaken for an independently produced response.

## Review or revise your message

Open the message's **Coach** feedback to inspect corrections and explanations. If you revise an earlier message, read the confirmation: later exchanges that depend on it may be removed. The [Coach guide](./coach) explains how feedback and clarification work.

To revisit the conversation later, open **Conversations** and select it. Use the app-wide [Progress](./progress) page to inspect accumulated results across conversations.
