The app's own toolbar icon set (source: ui/src/components/controls/ToolbarIcon.tsx), exported one per file. 24×24 viewBox, 1.7px round strokes. In the app they draw in `currentColor` (usually `ink-2`, `interaction-ink` when active); these files are inked in `ink` (#1f1c17) because an image can't inherit colour — to use them on dark, recolour the stroke to the dark `ink` (#f0f1f3) or use the inline SVG from the component.
